Multi-Agent Lab Assistant

An AI assistant for university research groups. One plain-English request, such as “check this reference, email the result and book a meeting”, is split into a plan and carried out by specialised agents that verify citations, send email, schedule meetings and track lab activity.

Labster · Research group assistant

i.

Reference-checking agent

Checks every citation in a submitted student essay against arXiv and Crossref, flags details that disagree with the published record, then reads each source’s abstract to judge whether it supports the claim it’s cited for.

ii.

LangGraph orchestration

A supervisor graph coordinates the reference, email, scheduling and admin agents, so one message can trigger a multi-step workflow with each step’s status reported back.

iii.

Email agent

Users just type email Sarah and ask her to come to the lab tomorrow. The agent writes the message and sends it to the right person, with approval before anything goes out.

iv.

Admin agent & the whole UI

Answers questions like who is in the lab?. I also designed and built the entire React/TypeScript interface: chat, conversation history, a meetings dashboard, members and Outlook connection.

03
Game AI · Search algorithms

Cascade Game-Playing Agent

An AI agent for Cascade, a two-player strategy board game, that beats an AlphaGo-style opponent by combining two classic search techniques.

Monte Carlo Tree Search

Simulates many possible games from the current position to find promising moves where the game tree is too large to search fully.

Minimax search

Looks ahead through both players’ best replies to pick moves that hold up against a strong, adversarial opponent.

  • Result: defeated an AlphaGo-variation agent in head-to-head play.
  • Ranking: placed 79th across the whole year level.
